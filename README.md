## Реализованные функции

- Кнопка "Загрузить пользователей" получает данные с `https://jsonplaceholder.typicode.com/users`, проверяет `response.ok` и выводит 10 пользователей
- Для каждого пользователя через DOM создаются имя, email и город
- Поле "Поиск по имени" фильтрует уже загруженный массив без нового HTTP-запроса, регистр игнорируется. Если в результате фильтрации не было найдено пользователей, выводится сообщение "Пользователи не найдены"
- У каждого пользователя есть кнопка "Показать публикации", при нажатии на которую выводится первые 3 публикации данного пользователя
- На время выполнения каждого запроса показывается статус "Загрузка...", блокируются кнопки "Загрузить пользователей" и "Показать публикации". Повторное нажатие возможно после получения ответа с сервера или показа ошибки

## Результаты проверки

- При нажатии на "Загрузить пользователей" появляются 10 пользователей с именем, email и городом, статус "Пользователи успешно загружены. Код ответа: 200"
- При вводе "leanne" в поиск остаётся только "Leanne Graham". При вводе "abc" выыодится сообщение "Пользователи не найдены"
- При нажатии на одном из пользователей на кнопку "Показать публикации" появляются заголовки и тексты первых трёх публикаций выбранного пользователя
- При временной замене `/users` на `/userz` (HTTP 404): появляется сообщение об ошибке. При возвращении правильного адреса повторный запрос работает
